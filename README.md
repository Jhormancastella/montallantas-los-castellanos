## ⚙️ Funciones principales

- 🧾 Registro de servicios y cálculo de totales.
- 👥 Administración de empleados y comisiones.
- 📦 Control de inventario y venta de insumos.
- 📊 Consulta de reportes y exportación a Excel.
- 🛍️ Catálogo de servicios.
